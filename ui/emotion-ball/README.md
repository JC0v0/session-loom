# Vendored Emotion Ball engine

Session-Loom embeds the small, dependency-free Emotion Ball renderer for the
守护进程 status indicator.

Source: https://github.com/sam70361/emotion-ball
Imported from commit: `b406eeb20a1b1ae0084d4006e77cc74e28be009d`

The four JavaScript files in this directory are the renderer and its data
layers. The vendored copy is intentionally kept independent of the gallery
site so it can run inside Session-Loom's local Tauri frontend.

license and usage notice.
